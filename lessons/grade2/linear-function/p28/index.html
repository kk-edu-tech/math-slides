問題一次関数 \(y=3x+5\) で、\(x\) が1から4まで変わるときの変わり方を調べよう。
\(x\)14
\(y\)817
\(x\)：3増える
→
\(y\)：9増える
では…
\(x\) が1増えるごとなら？
\[9\div3=3\]
数学の言葉
この「1増えるごとの変わり方」を 変化の割合 という。

中学2年数学まとめ
今日のまとめ
① \(x\) と \(y\) がそれぞれどれだけ増えたかを見る。
② \(x\) が1増えるごとの \(y\) の変わり方を 変化の割合 という。
③ 一次関数では、変化の割合は x の前の数 と同じ。
