# Math Slides Design Book v1.2

## v1.2 更新方針
- Problem Context（考え方ページの元問題）は、本文と同程度の読みやすい文字サイズで表示する。
- 問題文の改行は、意味のまとまり・句読点・条件と問いの境目を優先する。
- `x の増加量`、`変化の割合`、`毎分3L`、数式などの意味単位は可能な限り途中で分断しない。
- 文字が収まらない場合は、文字を小さくする前に自然な改行とレイアウト調整を行う。
- Teacher Modeは標準機能から削除する。
- タイマーは標準機能から削除する。
- 標準操作は「段階表示・前後移動・全画面」に絞る。

## 継続する原則
- 基本例題を中心に構成する。
- めあての次に「今日扱う問題」を表示する。
- 1画面1メッセージ。
- 問題 → 思考 → ヒント → 式 → 答え。
- 具体的事象 → 表 → 式 → 数の意味。
- 数学用語は意味理解のあとに示す。
- GitHub Pages版はMathJaxを使用する。
- APIキー等の秘密情報をフロントエンドに記載しない。

## 操作
- → / Space：次の段階、または次ページ
- ←：1つ戻る
- F：全画面
- 左右スワイプ：ページ移動
